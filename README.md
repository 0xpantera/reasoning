# reasoning

A from-scratch implementation of a reasoning model, developed alongside
Sebastian Raschka's *Build a Reasoning Model (From Scratch)*.

The book's notebooks and reference code live in the sibling
`reasoning-from-scratch` directory. This repository contains the clean,
package-oriented implementation.

## Setup

```bash
uv sync
```

## Development

```bash
uv run pytest
uv run ruff check .
```
